# Формат .tsx: брейкпоінти, значення, стрілки

Три конвенції, спільні для React + Tailwind проектів. Лінтера на них немає —
`eslint` мовчить, тож розбіжність накопичується непомітно. Еталон, який
вирішує спірні випадки: `example/games-today/src` (той самий стек, та сама
команда), якщо дерево є локально.

## 1. Класи групуються по брейкпоінтах

Плаский рядок лишається рядком, **поки всі класи з однієї групи**:

```tsx
className="w-full"
className="lg:relative lg:h-full lg:mb-0"
```

Щойно груп більше однієї — `cn([…])`, один рядок на групу:

```tsx
className={
    cn([
        'text-xs font-bold',
        'md:text-sm',
        'lg:text-md'
    ])
}
```

**Порядок груп:** база → `max-*` → `sm` → `md` → `lg` → `xl` → `xxl`.

**Немедійні варіанти лишаються в базовому рядку** — `hover:`, `rtl:`,
`group-hover:`, `data-[…]`, `[&_a]:`. Групу задає тільки медіа-брейкпоінт:

```tsx
cn([
    'flex rounded-lg hover:border-white/10 hover:text-accent',
    'sm:h-[50px] sm:w-[50px]',
    'md:text-sm md:[--icon-size:16px]'
])
```

**Умовні ключі об'єкта не розбиваються** — інакше вийшло б кілька ключів із
однаковою умовою:

```tsx
cn('grid …', {
    'md:grid-cols-[166px_167px] lg:grid-cols-[248px_248px]': casino.pros
})
```

**Форма виклику зберігається.** `cn([…])` і `cn(…)` з varargs обидві чинні;
беремо ту, що вже у файлі, і лише розкладаємо рядки по групах.

У компонентних CSS діє те саме правило через `@apply` — по рядку на групу,
**без порожніх рядків** між ними:

```css
.c-example__inner {
    @apply mx-auto;
    @apply md:w-full;
    @apply xl:h-full xl:w-1/3;
}
```

## 2. Значення приходить зі шкали й токенів теми

Довільне значення в дужках ставиться тільки тоді, коли в темі такого
значення немає. Ціна літерала та сама, що в піксельного медіа-запиту: він не
ходить за темою, і правка `--spacing` чи токена його мовчки обминає.

Крок шкали Tailwind 4 — 4px, і дробові кроки чинні, тож майже будь-яке
кругле число з макета в ній виражається:

```
px-[15px]    → px-3.75        min-w-[26px]   → min-w-6.5
leading-[20px] → leading-5    max-w-[1150px] → max-w-287.5
w-[194px]    → w-48.5         -me-[392px]    → -me-98
```

Те саме з іменованими токенами й змінними:

```
z-[100]                    → z-header / z-dialog   (шар — завжди токен)
max-w-[var(--content-column)] → max-w-(--content-column)
border-[2px]               → border-2              (ширина рамки — самі px)
```

**Лишаються в дужках** значення, яких у темі справді немає:
`max-w-[min(400px,calc(100vw-40px))]`, `bg-[#151515]`, `leading-[1.2]`,
`grid-cols-[1fr_1.5fr]`, `shadow-[0_0_16px_rgba(0,0,0,0.25)]`.

**Форми Tailwind 4, а не 3:** важливість — суфіксом (`z-60!`, не `!z-[60]`);
логічний край — `inset-s-*`/`inset-e-*`, не `start-*`/`end-*`; перенос слова —
`wrap-break-word`, не `break-words`; `shrink-0`/`grow`, не `flex-shrink-0`/
`flex-grow`.

**Інлайнове оголошення змінної** (`[--icon-size:16px]`) варте перевірки: коли
в проекті є утиліта, що цю саму змінну задає (тут `icon-4`), береться вона —
інакше поруч живуть два способи налаштувати одне й те саме.

## 3. Стрілка, яка нічого не повертає, дістає блокове тіло

Стосується і JSX-пропсів, і колбеків хуків, і cleanup-ів `useEffect`:

```tsx
onClose={
    () => {
        setActiveModal(null);
    }
}

useTimeout(
    () => {
        setIsOpen(false);
    },
    2000
)

return () => {
    clearTimeout(timer);
};
```

**Стрілки, що повертають значення, не чіпаються** — `queryFn`, `useMemo`,
`.map`/`.filter`/`.some`, `z.string({ error: () => t('…') })`,
`cache(async () => serverGraphApi(…))`, фабрики виду
`const make = () => new Thing()`.

Критерій — саме тип повернення, а не вигляд виклику. `() => this.create(x)`
виглядає як void-виклик, але `create` повертає об'єкт, тож лишається як є.
Коли неясно — прочитати сигнатуру, а не вгадати.

## Ревізія наявного коду

Чотири сканери, кожен друкує `file:line`. Запускати з кореня репозиторію;
приймають шляхи (за замовчуванням `src`):

```bash
node .claude/skills/tailwind-format/scripts/scan_classnames.mjs     # плоскі className із кількома групами
node .claude/skills/tailwind-format/scripts/scan_cn_order.mjs       # змішані рядки та порядок груп у cn()
node .claude/skills/tailwind-format/scripts/scan_values.mjs         # довільні значення замість шкали й токенів
node .claude/skills/tailwind-format/scripts/scan_arrows.mjs         # кандидати в блокове тіло
```

Сканери — на Node без залежностей, бо Node у проекті стека є завжди, а
Python — не на кожній машині. Перенесені в інший проект разом із текою,
працюють так само; `node` і `git` — усе, що їм треба. Windows покритий:
кирилиця у звіті друкується без налаштування консолі, файли з CRLF
(`core.autocrlf=true`) читаються як з LF.

`scan_values.mjs` дивиться `.tsx`, `.ts` і `.css` — саме туди, де проект
тримає класи: атрибут `className`, рядки-аргументи `cn(…)` і `@apply` у
компонентних CSS. Крок шкали заданий константою `STEP_PX` — змінити, якщо
тема перевизначає `--spacing`.

Його підказка — кандидат, а не вирок. Крок шкали він порахує завжди, але
там, де тема має **іменований** токен, правильна відповідь зазвичай він:
`max-w-[768px]` сканер зведе до `max-w-192`, а сказати варто `max-w-3xl` —
розмір той самий, а токен ще й каже, що це за ширина.

Дві родини потребують ока, а не пакетної правки: «поза шкалою» (значення є,
але мапінг задає тема — радіуси, кеглі, шари; або px, що не лягає на шкалу:
крок не кратний 0.25, як `w-[194.5px]`, чи дробова ширина рамки) і «оголошення змінної на місці»
(утиліта під цю змінну може не існувати — так у `[--spinner-*]`, які
налаштовують `u-spinner` з контексту й лишаються як є). Решта — однозначні.

`scan_arrows.mjs` типів не знає — він дає **кандидатів**, серед яких є
value-returning. Кожного треба звірити з сигнатурою перед правкою; скрипт уже
відсіває очевидне (`.map`, `.filter`, `z.`, `queryFn` тощо), але не все.

`scan_classnames.mjs` і `scan_cn_order.mjs` визначають порушення однозначно й
придатні для пакетної правки.

Після правок: перевірити, що `cn` імпортований у кожному торкнутому файлі
(`import cn from '@/lib/cn';`, в алфавітній позиції блоку `@/`-імпортів), і
прогнати збірку та лінт проекту.
