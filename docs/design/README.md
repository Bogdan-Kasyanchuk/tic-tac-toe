# Дизайн редизайну (жовтень 2026)

Копія канвасу https://claude.ai/artifact/PDTUiw8QMxFx1aLJRnp4US станом на 2026-10-16, щоб будь-яка сесія (VS Code, інший комп'ютер) читала дизайн без доступу до claude.ai.

- `*.dc.html` — по файлу на екран (артборд). Стилі інлайн: точні кольори, розміри, відступи й тексти беруться звідси. Розмітка `{{…}}`, `<sc-if>`, `<sc-for>` і блок `<script type="text/x-dc">` — це формат канвасу для інтерактивних прототипів, а не код застосунку. У браузері напряму файли не відкриваються, бо скрипт `support.js` є лише на канвасі.
- `canvas.json` — розкладка канвасу: назви екранів (`title`) і ряди.
- Відповідність екранів і коду — таблиця «Відповідність канвасу й коду» в `docs/superpowers/plans/2026-10-15-redesign-email-auth.md`.

Якщо дизайн змінюється на канвасі, онови цю теку новою копією, щоб код і файли не розходились.
